# VIVIA Creative Studio MVP

A lightweight browser-first working product prototype for the VIVIA creative-property model.

## Working now
- Create a creative property from a direction.
- Persist it locally in the browser.
- Display creative property state and creator authority.
- Continue an existing property without creating a new identity.
- Demonstrate the VIVIA continuity loop.
- Surface selected creative governance principles.
- Show a Mother Nature Protocol resource-planning signal.
- Explore CREATE, WORLDS, MEDIA, MAKE, LEARN and MARKET.
- Run without a database, API key, Firebase, or external runtime.

## Run
Open `index.html` or publish the repository root with GitHub Pages.

## Public boundary
This repository is the public VIVIA Creative Studio experience layer. It does not contain the private VIVIA implementation, internal contracts, schemas, tests, provider infrastructure, or governance kernel.

The creator loop demonstrated here is:

Intent → Create → Observe → Learn → Continue → Authorise → Express → Reuse → Create again.
